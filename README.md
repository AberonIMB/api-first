Этот проект - API для сервиса TODO List, предназначенного для управления личными задачами: создание, изменение, удаление и просмотр задач.

Какую нейронку использовал?
Пользовался моделью 6 Luna, но писал преимущественно вручную. У нейронки спрашивал про архитектуру спеки, из чего должны состоять её блоки и за что они отвечают. В некоторых местах просил сформулировать выражения покорректнее. Далее уже самостоятельно заполнял спецификацию.
Также просил проверить правильность работы, указать на ошибки и подсказать, как их можно решить.
